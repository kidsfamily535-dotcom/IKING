# THE KING'S EYE — الواجهة

منصة طيران خاص تربط العرض (طائرات متاحة) بالطلب (عملاء)، مع موافقة بشرية على كل إجراء خارجي.

## التشغيل على جهازك
```
npm install
npm run dev
```

## ما هو حقيقي وما هو محاكاة
- **حقيقي (بعد "دخول حقيقي"):** المطارات، الإشارات (التوافر الحالي + رصد الطائرات + إشارات الطلب)، سياسة القرار. مصدرها قاعدة Supabase المسماة "I KING".
- **محاكاة (SIM):** الفرص عند الأدمن، الموافقة والرفض، إضافة رحلة فاضية، رحلة العميل والذاكرة، فهم الطلب، العرض الكامل.
- لا يُرسل شيء لأي عميل أو مشغّل من هذه النسخة.

## الأمان
- المفتاح الموجود في الكود هو المفتاح **العام** (publishable) المسموح به في المتصفح. لا تضع أبدًا مفتاح `service_role` في هذا المشروع.
- الصلاحيات تحميها قاعدة البيانات (RLS)، وليس الواجهة.

## النشر على Vercel
1. ارفع المشروع على GitHub.
2. في Vercel اختر Add New → Project، واختر المستودع. الإعدادات الافتراضية (Vite) تكفي.
3. (اختياري) أضف المتغيرين `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY` من `.env.example`.

## المراحل
المجلد `phases/` فيه النسخ الأصلية لكل مرحلة (0 إلى 4) كملفات zip للرجوع إليها. الكود في الجذر هو الأحدث، ويحتوي المراحل 1–4 مع أول ربط حقيقي بـSupabase.
