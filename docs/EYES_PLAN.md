# خطة العيون — THE KING'S EYE

مرجع: ملف رؤية العيون (24 عين + أدوات Jetex + المحركات السبعة). القواعد الحاكمة: `CLAUDE.md` ودليل البناء. هنا ترتيب التنفيذ فقط.

## 1. الفكرة: عين كبرى واحدة + 3 طبقات
العين الكبرى (ملخص صباحي) فوق ثلاث طبقات. المستخدم يشوف عين واحدة، والباقي ذكاء تحتها.

| الطبقة | العيون المدموجة فيها |
|---|---|
| **عين الفرص** (مشغّل) | الطلب، الفرصة الصامتة، الحدث، العلاقة |
| **عين الإيراد** (مشغّل) | الأسطول، الرحلة الفاضية، التفاوض، الشبكة، النمو |
| **حارس الرحلة** (عميل + مشغّل) | الطقس، المطار، التأخير، الخطة البديلة، الطريق |
| **ملف الرحلة** (عميل) | المهمة، المسافر، الراحة، العائلة والأمتعة، ما بعد الرحلة |

كل عين تمشي على نفس الدورة: راقب ← افهم ← تحقق ← اقترح ← إنسان يوافق ← تابع ← تعلّم.

## 2. حالة كل عين
| الحالة | العيون |
|---|---|
| **شغالة بالبيانات الحالية** | تقرير الأسطول، الطيارة الواقفة، تقويم الطلب (الموجة 1)، **العين الكبرى (الموجة 2)** |
| **ممكنة جزئيًا (الطقس موجود)** | حارس الرحلة: طقس المطار METAR/TAF متخزن، ناقص رحلة مؤكدة نربطها بيه |
| **تحتاج مشغّل حقيقي** | الرحلة الفاضية، الرحلة العكسية، عين المحطة، التفاوض، كارت أداء المشغّل |
| **تحتاج عملاء حقيقيين** | العلاقة، الراحة، العائلة، ما بعد الرحلة (الذاكرة) |
| **لاحقًا (تكامل خارجي)** | الأرض والسواق، الشبكة، النمو |

## 3. قواعد على أفكار الرؤية (عشان ما نخالف CLAUDE.md)
1. **ممنوع أرقام مخترعة.** أمثلة الرؤية مثل «توفير 18,400$» و«هامش 10–12 ألف» و«احتمال إغلاق 87%» تتحسب من بيانات حقيقية (عرض مشغّل مؤكد) أو تتكتب «غير معروف». لا تظهر كرقم من غير مصدر.
2. **«فحصت البدائل» لا تتكتب إلا لو فحصناها فعلًا** وفيه نتيجة محفوظة.
3. **درجة العلاقة (مثلاً 92/100) تتحول** لحقائق سلوك مسجلة (آخر رحلة، متوسط الفترة بين الحجوزات). مفيش استنتاج نفسي عن العميل.
4. **بيانات العائلة والصحة والحركة** (كرسي متحرك، كبار سن) تتخزن فقط لو العميل نفسه قالها، وتتعدل وتتمسح.
5. **التفاوض والهامش داخلي للبروكر فقط.** الوكيل لا يذكر الهامش لأي عميل أو مشغّل، ويحوّل السؤال لإنسان.
6. **كل إرسال وكل موافقة** بإنسان، بالضغط المطوّل.
7. تتبع الطيارات: نوع + منطقة تقريبية، من غير رقم ذيل للعميل. وطيارة ظاهرة ≠ متاحة.

## 4. موجات التنفيذ
| الموجة | المحتوى | الحالة |
|---|---|---|
| 1 | الأسطول + الواقفة + تقويم الطلب (مرفوعة) | تمت |
| 2 | **العين الكبرى**: ملخص صباحي من بيانات حقيقية (فرص بتنتظر، طيارات واقفة بإشارة، فعاليات قريبة) | تمت في هذا الكوميت |
| 3 | **حارس الرحلة**: ربط METAR/TAF برحلة مؤكدة، خطر الطقس (LOW/MEDIUM/HIGH) + توصية بديلة بموافقة إنسان | بعد وجود رحلة مؤكدة |
| 4 | **قصة «يوم في حياة العين»** كعرض SIM واضح التعليم للمشغّل (من 07:12 إلى 22:15) | بعد الموجة 3 |
| 5 | الرحلة الفاضية + الرحلة العكسية | بعد أول مشغّل حقيقي |
| 6 | الذاكرة والراحة والعائلة | بعد عملاء حقيقيين |

## 5. قرارات مفتوحة
- نشر Vercel: المشروع مش ظاهر في الحساب المتوصل. محتاج رابط المشروع أو إعادة ربطه.
- تبديل اللغة عربي/إنجليزي: غير موجود في الكود (الواجهة عربي ثابت).
